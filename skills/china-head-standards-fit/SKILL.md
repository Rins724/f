# 中国头面部尺寸国标与头盔适配

本 Skill 为本仓库依据官方资料新编，2026-10-15；不是检索所得的第三方现成 Skill。按 MPL-2.0 发布，见 LICENSE。

## 核心依据与流程

1. 先读 [头面部尺寸与适配](references/head-dimensions-fit.md)。核心是 GB/T 2428-2024《成年人头面部尺寸》；需要成年男性三维头型时核查 GB/T 23461-2009。使用时重新查询官方状态、正文及适用人群，不能沿用已废止的 GB/T 2428-1998。
2. 沿用用户已确认的车型、年龄和目标人群；询问确实缺少的输入。明确这是单个骑手匹配，还是产品尺码与人群覆盖设计。
3. “头围多少、头型多少”必须对应标准具体表格、测量定义和人群。读取正文后才提取数值，附表号、单位、百分位与来源。暂时只有标准目录时，输出取数清单，不编造尺寸表。
4. 国标的人体测量数据是设计依据；它不等于某款头盔的适配证明。“亚洲版”需核对真实内腔、调节范围与试戴证据。中国标准中的样本范围应按正文描述，不能自动扩大到所有东亚人。
5. 输出尺寸依据、产品匹配结果和待验证项；若任务涉及头盔安全合格性，再读 [头盔产品标准核查](references/helmet-product-standards.md)，分别报告人体尺寸依据与产品检测证据。
