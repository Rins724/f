# 中国头盔标准核查
本模块由本仓库于 2026-10-15 新增，按同目录 MPL-2.0 发布；不是从 GitHub 找到的独立第三方 Skill。

## 使用
用于中国市场自行车头盔的标准适用性、设计要求与证据缺口核查。先确认普通自行车或电动自行车、目标年龄、用途及销售地区。沿用项目已确认信息。

## 已核对的官方入口
核对日期：2026-10-15。以下核对的是标准名称、状态和适用对象线索，未逐条审读全部标准正文或产品测试报告。每次实际审查应重新核对版本与适用范围。
- [GB 24429-2009](https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=A0DCCCDCD68FEE55B8FD25E5CC93E087)：现行，运动头盔——自行车、滑板、轮滑运动头盔的安全要求和试验方法。普通自行车头盔优先核查此标准的具体范围。
- [GB 811-2022](https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=30D37E4A3D526032511ED06AD33BF2A6)：现行，摩托车、电动自行车乘员头盔。不能直接替代普通自行车头盔的适用性判断。
- [GB/T 2428-2024 官方检索](https://openstd.samr.gov.cn/bzgk/std/std_list?p.p1=0&p.p2=GB%2FT2428&p.p90=circulation_date&p.p91=desc)：成年人头面部尺寸，现行，2025-04-01 实施。它是人体尺寸参考，不是头盔安全合格证据；1998 版已被替代。

## 核查流程
1. 从官方平台获取适用标准正文、修改单及实施信息；无法读取正文时，只报告版本核对结果，将条款与阈值列为待核对。
2. 对具体产品建立条款矩阵：标准及条款、要求、测试方法和条件、对应尺寸/材料/结构版本、已有证据、缺口、下一步。候选检索主题包括结构、覆盖与视野、佩戴装置、冲击性能、标识说明；仅在正文确认后作为正式条目，不声称此列表完整。
3. 头围规格、试验头型编号及几何尺寸必须逐条引用正文或正式检测材料，带页码、单位、版本。不得把试验头型当作消费者人口尺寸分布。
4. 检查报告的型号、尺码、配置、样品与当前设计一致性。通风开孔、壳体或缓冲材料、厚度、重量、固定装置变化时，记录影响，向检测机构确认需补做的验证。
5. 分别给出“标准适用性”“证据覆盖程度”“缺少的检测”。仅有图纸、品牌声明、尺寸匹配或舒适试戴不能判定整盔符合国标；不要推测必需认证制度或适用阈值。
6. 不提供未经证实的标准头围表、冲击限值、材料合格名单或自行制作的合格证。
